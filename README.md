# نوري — المرحلة الأولى: خدمة الحراسة

مشروع أندرويد (Kotlin + Jetpack Compose) يحجب التطبيقات المشتتة عند بلوغ السقف اليومي أو في وضع التركيز.

## التشغيل
1. افتح المجلد في Android Studio (Koala أو أحدث) ودعه يزامن Gradle (سينشئ الـ wrapper تلقائياً).
2. شغّل التطبيق على جهاز حقيقي (minSdk 26).
3. من التطبيق: «فتح إعدادات إمكانية الوصول» ← فعّل «نوري».
   - على أندرويد 13+ إن كانت الخيارات رمادية: إعدادات التطبيق ← ⋮ ← «السماح بالإعدادات المقيّدة».
4. اضبط السقف أو فعّل «وضع التركيز».

## كيف يعمل
- `GuardianAccessibilityService` يستمع لتغيّر النافذة فقط (`typeWindowStateChanged`) ولا يقرأ محتوى الشاشة.
- يحتسب وقت كل تطبيق مشتت ويفحص كل 5 ثوانٍ؛ عند بلوغ السقف ينفّذ `GLOBAL_ACTION_HOME`.
- `GuardianStore` يحفظ الإعدادات والاستخدام اليومي محلياً (يُصفَّر كل يوم).
- لا توجد صلاحية `INTERNET` في المانيفست إطلاقاً.

## الخطوات القادمة
- المرحلة 1ب: دمج Gemma عبر MediaPipe LLM Inference.
- نقل التخزين إلى Room + SQLCipher.
- Foreground Service واستثناء البطارية، ثم Device Admin، ثم اختبار التركيز لفك القفل المؤقت.
# 🌙 تطبيق نوري (Nouri App)

تطبيق لتعزيز التركيز وإدارة وقت استخدام الهاتف يعمل بمبدأ **الخصوصية التامة وبدون إنترنت (Offline-First)**، مدمج بذكاء اصطناعي محلي.

## 📌 الوضع الحالي للتطبيق (v0.1)
- **الميزات المتاحة حالياً:**
  - حجب بسقف يومي (Daily Limit).
  - وضع التركيز الأساسي (Basic Focus Mode).
- **النقاط المطلوبة للتطوير:**
  - وضع التركيز الحالي يمكن إيقافه بنقرة واحدة (سهولة التحايل).
  - عدم وجود جدولة زمانية للجلسات.
  - عدم وجود قائمة استثناءات لطوارئ الاتصال.

---

## 📑 مواصفات التطبيق والميزات المستوحاة

### 1️⃣ من تطبيق Keep Me Out
* **قفل سريع:** قفل الهاتف لمدة محددة بنقرة واحدة.
* **قفل مجدول:** تحديد أوقات القفل مسبقاً حتى أسبوع قادم.
* **إحصاءات الاستخدام:** تتبع دقيق لوقت الاستخدام لكل تطبيق.
* **قائمة طوارئ:** جهات اتصال تبقى متاحة للاتصال أثناء تفعيل القفل.

### 2️⃣ من تطبيق Freedom
* **جلسات حجب:** تبدأ فوراً أو بجدولة، وتتكرر يومياً أو أسبوعياً.
* **الوضع المقفل (Locked Mode):** يمنع إلغاء الجلسة أو إيقافها قبل انقضاء وقتها المحدد.
* **قوائم حجب:** قوائم حجب جاهزة ومخصصة، مع إمكانية حجب المواقع الإلكترونية مع استثناءات.
* **سجل الجلسات:** تتبع تاريخ الجلسات السابقة وأوقاتها.
> *ملاحظة:* تم استبعاد ميزة المزامنة بين الأجهزة لتعارضها مع فكرة التطبيق الأساسية (بلا إنترنت).

### 3️⃣ ما ينفرد به «نوري»
* 🧠 **ذكاء اصطناعي محلي (Local AI):** معالجة وتوجيه ذكي بالكامل داخل الجهاز.
* 👥 **وضع الصديق (Buddy Mode):** دعم وتحفيز بين الأصدقاء.
* 🔐 **ذاكرة مشفرة (Encrypted Storage):** حماية وتشفير تام لكافة بيانات الاستخدام والجلسات.
* 🛡️ **خصوصية كاملة (100% Privacy):** عدم إرسال أي بيانات لخوادم خارجية والعمل بدون اتصال بالإنترنت.

## 🛣️ خريطة طريق البناء والتطوير (Development Roadmap)

1. **المرحلة الأولى:** الجلسات المجدولة والمتكررة + القفل السريع بالمؤقت.
2. **المرحلة الثانية:** الوضع المقفل (Locked Mode) ومنع الإلغاء + قائمة طوارئ الاتصال.
3. **المرحلة الثالثة:** اختيار أي تطبيق للحجب + إنشاء سجل الجلسات.
4. **المرحلة الرابعة:** شاشة إحصاءات الاستخدام وتحليل الأوقات.
5. **المرحلة الخامسة:** حجب المواقع الإلكترونية (عبر قراءة شريط عنوان متصفح Chrome).
